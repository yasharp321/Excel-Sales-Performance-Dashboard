# 📊 Sales Performance Dashboard using Excel

## 📌 Project Overview
This project focuses on analyzing retail sales data and building an interactive dashboard using Microsoft Excel.  
The dashboard helps identify sales trends, category performance, and regional insights to support data-driven decision-making.

---

## 🧰 Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas (TEXT, YEAR, DATE)
- CSV Data Handling

  ![image alt](https://github.com/yasharp321/Excel-Sales-Performance-Dashboard/blob/main/Screenshot%202026-01-30%20131027.png?raw=true)

---

## 📂 Dataset
- Source: Superstore Sales Dataset
- Format: CSV
- Records: ~9,800 rows
- Key Columns:
  - Order Date
  - Sales
  - Category
  - Sub-Category
  - Region
  - Customer

---

## 🧹 Data Cleaning & Preparation
- Imported CSV using Excel's **From Text/CSV** option
- Converted text-based dates into proper date format
- Created derived columns:
  - Month
  - Year
- Ensured data consistency for analysis

---

## 📊 Analysis Performed
- Month-wise Sales Trend Analysis
- Category-wise Sales Performance
- Region-wise Sales Comparison
- Interactive filtering using slicers (Category, Region, Year)

---

## 📈 Dashboard Features
- Line chart for monthly sales trend
- Column chart for sales by category
- Bar chart for sales by region
- Fully interactive slicers for dynamic analysis

---

## 🎯 Key Insights

- Sales showed seasonal trends across years
- Certain regions consistently outperformed others
